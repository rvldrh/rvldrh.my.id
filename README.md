## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/rvldrh/rvldrh.my.id.git
cd rvldrh.my.id
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

## 🏗️ Build for Production

```bash
npm run build
npm start
```
